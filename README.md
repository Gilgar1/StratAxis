# StratAxis

StratAxis is a high-performance real estate analytics and prediction platform focused on the Cameroonian market (Yaoundé and Douala).

## Tech Stack
- **Frontend:** React, TailwindCSS, Chart.js
- **Backend:** FastAPI, Python
- **Database:** PostgreSQL + PostGIS
- **ML:** Scikit-learn, XGBoost, Prophet
