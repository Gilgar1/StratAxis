# Model Evaluation Metrics

## Regression Metrics (Price Prediction)
- **MAE (Mean Absolute Error)**: Average absolute difference between predicted and actual prices.
- **RMSE (Root Mean Square Error)**: Penalizes larger errors more heavily.
- **R² (Coefficient of Determination)**: Proportion of variance explained by the model (Goal: > 0.6).
- **Accuracy Within 20%**: Percentage of predictions within ±20% of actual values.

## Time Series Metrics (Trend Forecast)
- **MAPE (Mean Absolute Percentage Error)**: Measure of forecast accuracy.
- **Trend Direction Accuracy**: Percentage of times the predicted trend (Up/Down) matched reality.
